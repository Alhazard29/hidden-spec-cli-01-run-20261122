mend is a zero-dependency command-line tool that applies AI-written edits — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON text-editor tool calls — to a tree of text files, all or nothing. It finds the lines each edit names at the first of three matching tiers (exact, trailing-trim, full-trim), reports every failure, and writes nothing unless every edit succeeds.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
